# Equalizer 0.2.22 — the check of a version says what it does

Install: `INSTALL.md`, with `git checkout v0.2.22` and `EQ_VERSION=0.2.22`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.22`. Updating from
0.2.21: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. No
migration, no new setting.

## Changes you will notice

- **Verify** is now **Check this version on the site**, in a section
  called **Check on the site** that says what happens: the agent tries the
  version on a gateway of its own against the real site, compares every
  page with and without Equalizer, and has the gateway judge attacks on
  every input without sending them to the site. It changes nothing.
- It runs by itself after every discovery, so a checked version shows
  only a quiet **Check again** under its result; the button stands out
  only on a version never checked (a draft changed by hand).
- The three figures say what they mean, and the option to let the agent
  fix what it finds says that it makes a new draft you decide on.
- The guide's chapter "Check on the site (verification)" explains when it
  runs by itself, when to run it, and how to read it.
- The review aid no longer calls direct mode a lab-only setting: it is
  pointed out only when a version switches to it, with what to check.

## For operators

- Only the panel changes. The efficacy study passed on every lab site.
