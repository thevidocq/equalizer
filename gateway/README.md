# gateway

Go service, the only exposed component. It applies the signed map, rebuilds
requests to the legacy application and renders pages with faithful rendering.

## Layout

```text
cmd/gateway/          startup, signals, healthcheck
internal/config/      environment variables
internal/telemetry/   logs, request_id, events
internal/clientip/    real client IP
internal/mapmodel/    map types
internal/mapstore/    signed map: verification and reload
internal/site/        compiled map: router, validator, client, budget
internal/router/      route allowlist
internal/validate/    types and constraints of input values
internal/placeholder/ {{space.name}} placeholders in legacy_request
internal/legacyclient/ rebuilt requests and filtered responses
internal/legacyurl/   legacy URLs → public URLs (links, compat, routes)
internal/formmap/     legacy <form> → declared form (action, hidden inputs)
internal/formtoken/   sealed form state (AES-256-GCM), browser binding
internal/session/     gateway sessions: Redis or memory store, encryption
internal/limits/      rate limits and behaviour rules (Redis or memory counters)
internal/charset/     page encoding and conversion to UTF-8
internal/pipeline/    faithful rendering: Step, Context, clean/, forms/ and rewrite/ steps
internal/thirdparty/xhtml/ HTML5 parser (copy of golang.org/x/net/html)
internal/transport/   link to the legacy application (direct, or relay → connector)
internal/budget/      concurrent requests to the legacy application
internal/server/      public and admin handlers
```

## Environment variables

| Variable | Default | Meaning |
| --- | --- | --- |
| `EQ_PUBLIC_ADDR` | `:8080` | Public traffic (behind Caddy) |
| `EQ_ADMIN_ADDR` | `:9090` | `/healthz`, `/readyz` (sites loaded), `/tls/allowed?domain=` (Caddy on-demand certificates); internal networks only |
| `EQ_INSTANCE` | hostname | Instance name in logs |
| `EQ_LOG_LEVEL` | `info` | `debug`, `info`, `warn`, `error` |
| `EQ_MAP_URL` | — | Panel endpoint with every published map (`/v1/internal/maps`, ETag); each map is served on its `meta.public_domain`. Empty: `EQ_MAP_FILE` |
| `EQ_OIDC_SECRETS_URL` | next to `EQ_MAP_URL` | Panel endpoint with the client secrets of sites logging in with OIDC (`/v1/internal/oidc`), read every 15 s |
| `EQ_MAP_FILE` | `/maps/current.json` | Signed document (SignedMap, or `{"items": [...]}`); a single map without `public_domain` is served for every host |
| `EQ_MAP_PUBKEY` or `EQ_MAP_PUBKEY_FILE` | — | Ed25519 public key in base64 (required) |
| `EQ_MAP_KEY_ID` | — | Expected key id (optional) |
| `EQ_TRUSTED_PROXIES` | — | CIDR networks from which the client IP in headers is accepted |
| `EQ_FORM_KEY` or `EQ_FORM_KEY_FILE` | random | Gateway secret (32 bytes, base64): seals form tokens and, through a derived key, sessions; must be the same on every replica |
| `EQ_RELAY_URL` | — | tunnel-relay internal address (e.g. `http://tunnel-relay:8082`); without it connector mode answers 502 |
| `EQ_RELAY_TOKEN` or `EQ_RELAY_TOKEN_FILE` | — | Token presented to the relay (at least 32 characters) |
| `EQ_REDIS_URL` | — | Sessions and rate-limit counters, e.g. `redis://redis:6379/0`; without it both live in memory (single replica only) |
