# Equalizer 0.2.19 — the assistant says why the AI did not answer

Install: `INSTALL.md`, with `git checkout v0.2.19` and `EQ_VERSION=0.2.19`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.19`. Updating from
0.2.18: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. No
migration, no new setting.

## Fixed

- When the AI provider refused a question (a wrong or expired key, no
  credit, a model that does not exist), the assistant showed an empty
  answer. It now says what happened and what to do, for example "the AI
  provider refused the API key: check it in Settings → AI".
- Any error of the panel now always comes with words, even when a proxy
  dropped the server's message.

## For operators

- The assistant answers a provider's refusal with HTTP 424 (was 502).
- The efficacy study passed on every lab site (`docs/efficacy.md`).
