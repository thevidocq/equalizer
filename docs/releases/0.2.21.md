# Equalizer 0.2.21 — tidier sites, settings and logs

Install: `INSTALL.md`, with `git checkout v0.2.21` and `EQ_VERSION=0.2.21`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.21`. Updating from
0.2.20: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. No
migration, no new setting.

## Changes you will notice

- **Delete** a site from the list of **Protected sites** (one button per
  row, administrators); a site's header keeps only **Ask AI**.
- **Settings**: the section is called **AI model**, since discovery, the
  review of a version and the assistant all use it.
- **Logs**: the table takes the whole width and never scrolls sideways; a
  row opens its detail right under it (click again to close). On narrow
  screens the site and the address columns give way, the request is cut
  to fit.

## For operators

- Only the panel changes. The efficacy study passed on every lab site.
