# Equalizer 0.2.29 — the source reader

Install: `INSTALL.md`, with `git checkout v0.2.29` and `EQ_VERSION=0.2.29`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.29`. Updating from
0.2.28: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. One
migration (`0030_source_readers.sql`, applied at start), no new setting on
the platform.

## New

- **The source reader** (optional, the site's new **Source** tab). A small
  container next to the connector, never on the web server, reads the
  site's code read only, by SFTP with its own key, a Windows share or a
  mounted folder, and sends Equalizer a summary: entry points, the type
  the code gives each field, the calls where a request value may do harm,
  components and versions. The code, the values and the secrets never
  leave the customer's network; `wp-config.php`, `.env`, keys and uploads
  are never opened. The tab shows the reader's key to authorise, the
  command that starts it, whether it answers, and the last read (**Read
  now** tests the settings).
- **Discoveries read the source**: **Read the site's source code**,
  checked by default once the reader answers, grey until then. Fields the
  agent would leave as free text get the code's type (a number, an email,
  one of a few values) when the code always reads them so and the values
  seen fit. The report gains **From the source code**: the fields typed,
  the entry points no link shows, the risky calls with file and line, the
  components. This release reads WordPress and plain PHP.

- **Rename a site**: the pencil next to its name (administrators). Only
  the name changes: domain, address and map stay the same.
- The source reader never reads the files with credentials of any
  supported application, nor the usual names of a custom site's settings,
  nor a file with a password written in it (the list is in the manual).

## For operators

- New image `ghcr.io/thevidocq/equalizer-source-reader` (published by CI
  like the others; make the package public or `docker login ghcr.io`).
  Customers run it from the command in the Source tab.
- The reader calls the panel at `EQ_PANEL_URL` under `/v1/source/`, with
  its site's token: the panel's address must be reachable from the
  connector's network, as it is from browsers.
- panel-api, panel-ui, agent. The efficacy study passed on every lab site
  (`docs/efficacy.md`).
