# Equalizer 0.2.6 — first discovery of a site reached directly

Install: `INSTALL.md`, with `git checkout v0.2.6` and `EQ_VERSION=0.2.6`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.6`. Updating from
0.2.5: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. No database
change.

## Fix

- **The first discovery of a site reached directly now proposes a map.**
  The site's template is written for a connector; on the first discovery
  the panel handed it to the agent with the connector left empty, so a site
  reached directly ended with *"the proposed map: no connector "" in this
  tenant"*. The reach chosen for the site (direct or connector) now replaces
  the template's, as it already did for a template opened by hand on the
  Map tab.

## For operators

- After the update run `deploy/compose/check.sh`.
- `EQ_DIRECT_DESTINATIONS` entries must be `host:port`; a malformed entry
  stops panel-api at start. For a public site reached directly by name you
  do not need it: the address goes in the site's reach.
