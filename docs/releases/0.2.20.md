# Equalizer 0.2.20 — History and New no longer break the page

Install: `INSTALL.md`, with `git checkout v0.2.20` and `EQ_VERSION=0.2.20`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.20`. Updating from
0.2.19: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. No
migration, no new setting.

## Fixed

- In recent Chrome and Edge, **History** or **New** in the assistant
  showed "Unexpected Application Error! … is not a function": the panel
  scrolled the conversation in a way those browsers answer with a
  Promise, which React then tried to call. Fixed, and the panel's build
  checks now refuse that way of writing it anywhere.

## For operators

- Only the panel changes. The efficacy study passed on every lab site
  (`docs/efficacy.md`).
