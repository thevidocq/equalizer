# Equalizer 0.2.30 — a cleaner discovery, an honest source report

Install: `INSTALL.md`, with `git checkout v0.2.30` and `EQ_VERSION=0.2.30`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.30`, source reader
`ghcr.io/thevidocq/equalizer-source-reader:0.2.30`. Updating from 0.2.29:
`INSTALL.md`, "Update", then `deploy/compose/check.sh`. One migration
(`0031_scanner_status_source_container.sql`, applied at start); one new
optional setting, `EQ_DISCOVERY_BROWSER_PAGE_SECONDS` (20).

## New

- **Discovery, simpler.** No "Use AI" checkbox: the AI is used whenever
  your organisation has a model, and a soft amber notice says when it has
  none. Test accounts and the page limit are folded under an arrow.
- **Nothing silent any more.** The browser step says which page it is on
  and gives a page 20 seconds at most: a page skipped is listed in the
  report, with why, and in Still open. The check of a draft says where it
  is ("comparing pages…: page 120 of 349").
- **Logs: click a bar** of the refused chart to see that hour's refused
  events.
- **Settings → Security scanner**: CVE Radar in a card, with whether the
  key still works (Connected, Not connected, Key refused).
- **Source reader**: the report keeps to the site's own code (plugins,
  themes, custom files), grouped by plugin; no false "command run" from
  SQL backticks; one Components list. A site in Docker: name its
  container in the Source tab, the command mounts it.
- On phones, the site's tabs scroll on their own row.

## For operators

- Recreate a source reader on a Docker site from the Source tab's new
  command (it mounts the container's volumes read only).
- The efficacy study passed on every lab site (`docs/efficacy.md`).
