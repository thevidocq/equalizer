# Equalizer 0.2.25 — links with accented or non-Latin characters

Install: `INSTALL.md`, with `git checkout v0.2.25` and `EQ_VERSION=0.2.25`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.25`. Updating from
0.2.24: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. No
migration, no new setting.

## Fixed

- **"Check on the site" called almost every page broken** on sites with
  links to addresses with non-Latin or accented characters (a WordPress
  tag `/tag/greek/%ce%b5…` in the tag cloud of every page: 272 of 300
  pages "lose links"). The gateway wrote those links as `%CE%B5…`: the
  same address for the browser, different text for the check. Now:
  - the gateway keeps the page's own spelling of a link whose path does
    not change;
  - the check compares where links, redirects and forms lead, so the
    case of `%xx` no longer counts as a difference.

  Run the discovery again (or **Check again** on the draft) to get the
  right numbers.

## Security

- A link the legacy site writes as `//other-host/…` (a path starting with
  two slashes) could come out of the gateway as a protocol-relative URL
  to another host, in pages and in redirects. It now stays a path on the
  site (`/.//other-host/…`).

## For operators

- Gateway and agent change. The efficacy study passed on every lab site.
