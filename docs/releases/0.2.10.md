# Equalizer 0.2.10 — safer discovery, one draft, visitors' requests in one click

Install: `INSTALL.md`, with `git checkout v0.2.10` and `EQ_VERSION=0.2.10`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.10`. Updating from
0.2.9: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. No database
change, no new setting.

This release went through independent reviews (several rounds, a security
one among them) of everything changed since 0.2.8; the findings are fixed
and tested.

## Changes you will notice

- **One draft to review.** After a discovery the agent verifies its draft
  on the gateway and corrects it before you look at it: the discovery page
  says when it is still working, then shows the one draft to review with
  its measure and corrections. A draft you have already submitted is never
  replaced.
- **Visitors' requests, decided by you in one click.** Files and page
  options (`?orderby=`) that visitors asked for and the map refuses are
  listed in the discovery report, never added by the agent: anyone can ask
  for anything. For each, the agent says whether the site itself uses it
  and what adding it would open; **Add to a new draft** makes the change.
  Each click adds to the same draft.
- **The agent adds to a folder only passive types** (images, fonts, audio,
  video, stylesheets, PDF and office documents; scripts a page loads), never
  text, CSV, archives, HTML or XML on its own.
- **Discovery finds more:** fonts and images named only in stylesheets,
  lazy-loaded and responsive images, video posters, documents, sitemaps by
  any name (WordPress's `/wp-sitemap.xml`), links written with the site's
  other names (`www.`, public domain), the page options its links use.
- **Videos:** streamed with seeking; a paused player no longer holds the
  site (streams use at most half the legacy capacity, two per visitor); a
  visitor closing a video is not a site error; Safari's first request works.
- **Fonts and images:** fonts are judged by their content (any declared
  type), AVIF and HEIF images pass.

## Security

- The learning loops can no longer be steered by anonymous visitors (files,
  query keys, capability URLs).
- A chosen byte range can no longer skip the media check; a 416 no longer
  reveals the size of a file the map does not serve.
- HTML and XML assets get a CSP sandbox; an asset response carries the one
  type that was checked.
- The agent never opens links that end the session or act on the site,
  whatever their spelling (log off, sign out, `/connect/endsession`, other
  languages, `/logout.png`).
- Multipart field names with a backslash are refused.

## What to do

- Run discovery again on your sites and review the proposed draft; look at
  the visitors' lists in the report.

## For operators

- After the update run `deploy/compose/check.sh`.
- A site with `max_concurrency: 1` streams one video at a time.
