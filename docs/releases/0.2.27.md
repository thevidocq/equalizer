# Equalizer 0.2.27 — security scans

Install: `INSTALL.md`, with `git checkout v0.2.27` and `EQ_VERSION=0.2.27`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.27`. Updating from
0.2.26: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. One
migration (`0028_security_scans.sql`, applied at start), no new setting.

## New

- **Security tab** on every site: scan it with your own CVE Radar account
  and see every finding with what the published map does with it
  (Closed, Checked, Free text, Area only, File, Server).
  - **Through Equalizer**: the public domain, as visitors reach it: what
    is left open.
  - **Original site**: the legacy site's own name, without Equalizer, for
    a before and after. It asks you to confirm that the site is yours or
    that its owner allowed it in writing; Activity records it.
  - Standard or deep scans, one at a time per target; the tab follows the
    scan and shows the findings when it ends.
- **Settings → Security scanner**: the address of CVE Radar's API and a
  key (read, scan and write permissions). Tried before saving, kept
  encrypted, shown only as its last four characters.
- **Activity** tells who connected the scanner, who started each scan
  (and confirmed the original site), and when scans end or fail.

## For operators

- panel-api reaches the scanner's API on port 443 (public addresses
  only). The efficacy study passed on every lab site (`docs/efficacy.md`).
