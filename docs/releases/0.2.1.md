# Equalizer 0.2.1 — what the first installation showed

Install: `INSTALL.md`, with `git checkout v0.2.1` and `EQ_VERSION=0.2.1`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.1`. Updating from
0.2.0: `INSTALL.md`, "Update". The database changes apply on their own at
start (migrations 0018–0020).

## Changes you will notice

- **One administrator publishes alone.** Roles are administrator and viewer.
  Editors and approvers become administrators, auditors viewers.
- **Direct mode**: a site that stays at its public IP address and accepts
  only Equalizer's addresses needs no connector. The panel shows
  Equalizer's addresses (`EQ_OUTBOUND_IPS`, or those of the panel's and
  relay's domains).
- **Delete a customer** (platform administrators), the id typed again to
  confirm.
- **Isolation**: "the site never had a public address"; Equalizer's own IP
  is refused as an old IP; isolation of a site reached directly is tested
  from another network.
- **AI settings** list the provider's models. **Alerts**: each kind on or
  off.
- **Panel on phones**: a top bar with a menu, tables that scroll, no
  squeezed columns.

## Fixes

- A gateway with no site yet is shown running, not down.
- `EQ_MAIL_FROM` with a name (`Equalizer <noreply@…>`) works; an unsent email
  says why. Invitations to an email already in use are refused at once;
  "Invite again" is prefilled.
- http to https of an https site is temporary (302/307), no HSTS on plain
  http: switching a site to http no longer leaves browsers stuck on https.
- A legacy application that sends visitors to the same page in the other
  scheme (a WordPress address in https while the site is served in http)
  gets a clear page and a "Site settings disagree on http/https" event
  instead of a redirect loop.
- The connector command includes the relay's address.
- go-redis 9.7.3 (Dependabot).

## Decisions

- Site certificates are always the original site's own, uploaded in
  **Site → Certificate**: Equalizer never issues one for a protected site.

## Tested

Go, panel and agent tests; the local end-to-end lab against ten web
applications (79 tests); the panel at phone width.
