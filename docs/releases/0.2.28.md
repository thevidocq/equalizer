# Equalizer 0.2.28 — scans that harden what they find, quick scans

Install: `INSTALL.md`, with `git checkout v0.2.28` and `EQ_VERSION=0.2.28`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.28`. Updating from
0.2.27: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. One
migration (`0029_security_drafts.sql`, applied at start), no new setting.

## New

- **A draft after every scan.** When a security scan ends, Equalizer
  builds one map draft that hardens what the map can by itself: the text
  rule that refuses the attack the scanner found on a free-text input
  (markup, SQL characters, template sequences); a mitigation, scan again
  once published. The draft is in the **Map** tab like every other one,
  takes the place of the draft waiting there (or points to the version
  already waiting that hardens them), is checked on the site by the agent,
  and is yours to review and publish. The Security tab links it and marks
  each finding it hardens; when there is none, the card says why. While a
  version is in review or a draft is being checked, it waits and tries
  again for a day.
- **The assistant reads the security scans**: ask "what is still open?",
  "is this finding serious?", "how do I close it?". It answers from the
  Security tab, says what the map does with each finding, points to the
  draft that hardens it, and explains what is left to fix on the server.
  It never sends the scanner's evidence (cookies, tokens) to the AI
  provider.

- **Quick scans**: seconds instead of minutes (headers, HTTPS, cookies,
  email DNS, technologies, exposed files), from the same **Scan now**.
