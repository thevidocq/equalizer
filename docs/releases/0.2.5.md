# Equalizer 0.2.5 — direct mode by name works end to end

Install: `INSTALL.md`, with `git checkout v0.2.5` and `EQ_VERSION=0.2.5`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.5`. Updating from
0.2.4: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. No database
change.

## Fix

- **Direct mode by name now works for discovery too.** 0.2.4 let the panel
  and the gateway reach a site directly by name (a public name that resolves
  to public addresses only, e.g. a site behind a CDN), but the **discovery
  agent** still had its own IP-only check and failed with
  *"direct mode reaches a public IP address, or a destination in
  EQ_DIRECT_DESTINATIONS"*. The agent now applies the same rule as the
  gateway: a name is resolved at connect time and the connection goes only
  to a public address — a name that resolves (now or by rebinding) to a
  private or reserved address is refused. Discovery against a site reached
  directly by name now runs.

## Note for this setup

For a public site reached directly by name you do **not** need
`EQ_DIRECT_DESTINATIONS`: enter the site's address as `host:port` in the
site's reach (direct mode), for example `www.example.com:443`. The port is
required. `EQ_DIRECT_DESTINATIONS` is only for destinations that are *not*
public (lab or internal applications), and each entry there must include the
port.
