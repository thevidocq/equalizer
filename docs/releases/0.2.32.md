# Equalizer 0.2.32 — the AI's security study of the site

Install: `INSTALL.md`, with `git checkout v0.2.32` and `EQ_VERSION=0.2.32`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.32`, source reader
`ghcr.io/thevidocq/equalizer-source-reader:0.2.32`. Updating from 0.2.31:
`INSTALL.md`, "Update", then `deploy/compose/check.sh`. No migration, no
new setting.

## New

- **Every discovery ends with a security study.** The AI reads everything
  the discovery found, on the surface and in the code: each page, form
  and API entry with the type of each field, the components and their
  versions, what stayed open, what visitors asked for and, when the
  source code was read, the entry points only the code shows and the
  risky calls with the field that reaches them. It studies them together,
  as a security engineer and a developer would, and writes a summary, the
  attack surface, the first steps, and the findings ranked: why, what an
  attacker would try, how far the map stops it once published, and the
  next step. It sees names, types and places only, cites only what the
  discovery found, and changes nothing in the draft. The assistant reads
  it too: ask it about any finding.

## Fixed

- **Source reader, a closer reading.** WordPress REST routes and AJAX
  actions written with constants, properties or variables are found
  (WooCommerce: 341 REST routes, before none); a request value kept in a
  variable and then used in a query, a file write or an include counts as
  a risky call; comment lines never do; `filter_input()` types a field;
  a method called `exec` (PDO) is no longer a command.
- **Source reader, safety.** A folder on an SMB share named like an
  smbclient command (`a;!cmd`) can no longer run that command on the
  reader's machine; a FIFO or device named like code no longer blocks a
  read; a file that grows while being read is not read past 1 MB; a value
  that looks like a token or password, compared with a request key, never
  leaves the customer's network.
