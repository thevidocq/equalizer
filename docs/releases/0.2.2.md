# Equalizer 0.2.2 — second round of feedback

Install: `INSTALL.md`, with `git checkout v0.2.2` and `EQ_VERSION=0.2.2`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.2`. Updating from
0.2.1: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. The database
changes apply on their own at start (migrations 0021–0023).

## Changes you will notice

- **HTTPS handled by a proxy in front** (Cloudflare or any other): a third
  choice in Site → Certificate. The site is served on the plain port with
  https addresses and Secure cookies, without certificate or HSTS. Sites
  behind such a proxy that were set to plain HTTP should switch to it
  (the WordPress editor's Publish needs it).
- **Dates** written the same way everywhere ("21 Nov 2026, 02:33:07
  UTC+1"), in the time zone chosen in **Your account** (UTC by default);
  alert emails too.
- **Activity**: search, period (presets or from day to day), **Show
  older**; every action written as a sentence, the agent and Equalizer
  named for what they did.
- **Logs**: alerts have a title and name the connector; rows that only
  concern requests are hidden when not relevant.
- **Continuous discovery** at the hour and weekday you choose, with the next
  and the latest run.
- **Discovery**: a spinner while it runs; when the AI was asked but not
  used, the report says why in plain words (no credit, key refused,
  provider down).
- **Release** at the bottom of the sidebar, with its release notes.

## Fixes

- The review of a published version compares it with the one published
  before it; leftover approval wording removed.
- No repeated "Served / Served" in Logs.

## For operators

- `deploy/compose/check.sh`: the check to run after every update.
