# Equalizer 0.2.8 — fonts and videos of the legacy site

Install: `INSTALL.md`, with `git checkout v0.2.8` and `EQ_VERSION=0.2.8`;
connectors `ghcr.io/thevidocq/equalizer-connector:0.2.8`. Updating from
0.2.7: `INSTALL.md`, "Update", then `deploy/compose/check.sh`. No database
change, no new setting.

## Changes you will notice

- **Fonts load.** Many legacy servers send `.woff`/`.woff2`/`.ttf` files as
  `application/octet-stream` or with an old name (`application/x-font-woff`),
  and the gateway refused them (`asset_type_not_allowed`) even with
  `font/woff` in the map. A font is now recognised by its content and served
  with the right type when the map allows it. A file that is not a font is
  still refused, whatever its name.
- **Videos and audio play.** Files such as `.mp4`, `.webm` or `.mp3` were
  refused above 16 MiB (`response_too_large`). They are now streamed, and
  players can seek (byte ranges). The default limit for media is 512 MiB
  (`max_size_kb` on the asset prefix to change it).

## What to do

- To serve a video, its asset prefix must list the type: add `video/mp4`
  (or `video/webm`, `audio/mpeg`, ...) to the prefix's `types` in the map and
  publish it. Discovery does not yet add it to a prefix already in the map.

## For operators

- After the update run `deploy/compose/check.sh`.
- A streamed video holds one slot of the site's legacy budget while it is
  being sent, like a large download through an area.
